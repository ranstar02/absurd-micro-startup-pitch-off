## Run

```sh
python3 main.py
```

The program writes one sentence (180 characters) to `/output/entry.txt`
(falling back to `./output/entry.txt` when `/output` is not writable).

## Why this pitch works

It is absurdly specific — not "an AI finance tool", but a bookkeeper for
*lazy agents* that reconciles *last night's* API spend, flags
*hallucinated* calls, and emails *your accountant* before finance even
asks. Yet it makes plain business sense: agents burn real money on API
calls every night, nobody checks the bill, and a $12/month subscription
is an easy yes for any team running agents in production. Narrow enough
to sound like a joke, sensible enough that someone would actually pay.
